# Quant (macOS) — Releases

This repo hosts public download/update files for the [Quant](https://quant.gammastudios.xyz) desktop app. Source code lives in a private repository; this repo exists only so the app's auto-updater and DMG downloads can be fetched without authentication.

No source code, user data, or secrets live here — only build artifacts (`.dmg`, `.app.tar.gz`, update signatures, and the updater manifest) attached to each [release](../../releases).
